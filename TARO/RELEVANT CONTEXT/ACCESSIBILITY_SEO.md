# Доступность и SEO

## Семантика и ARIA
- Использовать `header`, `main`, `section`, `footer` по назначению.
- В `index.html` секции помечены `aria-labelledby`. Поддерживать уникальные id заголовков.
- Для интерактивов: `aria-label`, `aria-controls`, `aria-expanded`.
- Иконки как декор — `aria-hidden="true"`/`role="presentation"`.

## Клавиатура
- Фокус‑стили не убирать на интерактивах: использовать видимые состояния там, где требуется.
- Управление бургер‑меню — корректные `aria-expanded` и управляемые элементы.

## Контент и изображения
- `alt` для изображений, `source` с WebP + fallback.
- Текст контрастный: светлый на тёмном фоне, проверять WCAG AA.

## SEO
- Title и meta description заданы.
- Open Graph и Twitter Card настроены (заголовок/описание/тип/URL/имя сайта).
- Структура заголовков: один H1 в Hero, далее иерархия H2/H3.
- ЧПУ ссылок внутри страницы — якоря `#id`.

## Производительность (пересечение)
- Предзагрузка критичных ресурсов (шрифты, стили) при необходимости.
- Ленивая загрузка изображений, минимизация блокирующих рендер ресурсов.

## Тест‑чеклист
- Навигация с клавиатуры возможна и понятна.
- Фокус видим на всех интерактивных элементах.
- Атрибуты `aria-*` согласованы и валидны.
- Meta/OG/Twitter заполнены корректно.
