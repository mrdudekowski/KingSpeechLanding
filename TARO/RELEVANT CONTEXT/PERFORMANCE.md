# Производительность

## Изображения
- WebP по умолчанию, есть JPG/PNG fallback.
- `picture` + `source` для современных форматов.
- Корректные размеры, отсутствие лишних мегабайт.

## CSS/JS
- Минимизировать блокирующие рендер ресурсы.
- Отложенная загрузка скриптов (`defer`).
- Сбор редко используемого функционала в отдельные файлы (по необходимости).

## Шрифты
- Подключения через Google Fonts (`display=swap`).
- Использовать ограниченные наборы начертаний.

## Ленивая загрузка
- Lazy‑loading изображений (в `main.js`), отложенные эффекты.

## Метрики
- LCP: оптимизация Hero (сжатый фон, ограничение эффектов на мобилах).
- CLS: стабильные размеры контейнеров и изображений.
- TBT/INP: минимальный JS, отсутствие тяжелых обработчиков при загрузке.

## Рекомендации
- Аудит Lighthouse (Performance, Best Practices, SEO, Accessibility).
- Использовать кеширование на уровне CDN/хостинга статических файлов.
