# Single Source of Truth (SoT)

## Принцип
Одна каноническая точка для каждого типа знаний:
- Дизайн‑токены — только в `styles/main.css` (`:root`).
- Типографика — базовые семейства и правила в `styles/main.css`; исключения (например, Hero H1) — локально и явно.
- Подключения шрифтов/внешних CDN — только в `index.html`.
- Гайды и регламенты — в `RELEVANT CONTEXT/*`.

## Запреты
- Не дублировать константы цветов/размеров/токенов в разных файлах.
- Не подключать внешние библиотеки из разных мест.

## Аудит
- Периодически просматривать `styles/*.css` на наличие "магических чисел".
- Ссылаться из документации друг на друга, не копируя одинаковые фрагменты.
