# Зависимости

## Внешние
- Google Fonts:
  - Inter (веса: 300, 400, 500, 600, 700)
  - Source Sans 3 (ось веса 200–900, ital 0/1)
  - El Messiri (веса 400–700)
- Font Awesome 6.5.1 (CDN) — иконки (телефон, мессенджеры, стрелки).

## Внутренние
- `taro-landing-site/scripts/*.js` — базовая логика страницы: init, resize manager, canvas эффект.
- Изображения: WebP/JPG/PNG в `assets/images/`.

## Примечания
- Все подключения находятся в `index.html` (шрифты, Font Awesome, стили, скрипты).
- Явных NPM‑зависимостей для работы страницы нет (статический билд). Node‑зависимости могут использоваться только для локальных задач/пакетов (см. `package.json`), не обязательны для деплоя статики.
