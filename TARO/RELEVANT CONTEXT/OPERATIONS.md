# Операции (запуск и деплой)

## Локальный запуск
- Достаточно открыть `taro-landing-site/index.html` в браузере.
- Для корректной работы путей/шрифтов/кеша — рекомендовано поднять простой статический сервер (например, `npx http-server taro-landing-site -p 8080`).

## Структура ассетов
- Изображения: `assets/images/` (WebP/JPG/PNG). Следить за размерами/сжатием.
- Иконки: `assets/icons/`.
- Стили: `styles/*.css`.
- Скрипты: `scripts/*.js`.

## Деплой
- Любой статический хостинг (Netlify, Vercel, GitHub Pages, S3+CloudFront, Nginx).
- Точка корня: папка `taro-landing-site/`.
- Кеширование: включить длительное кеширование для изображений/иконок/шрифтов; короткое — для HTML/CSS/JS при активной разработке.

## Контроль качества перед деплоем
- Проверить Lighthouse (Performance/SEO/Accessibility/Best Practices).
- Прогнать ручной чеклист доступности (клавиатура, фокус, aria).
- Проверить адаптивность на ключевых брейкпоинтах (480/768/1200+).
