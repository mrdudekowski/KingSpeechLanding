# 📚 Документация проекта "Нервная Лола"

Добро пожаловать в документацию веб-сайта кофейни "Нервная Лола"!

## 📂 Структура документации

### 🏗️ [`architecture/`](./architecture/)
Техническая архитектура и технические спецификации:
- **TECHNICAL_REPORT.md** - Полный технический отчет проекта
- **CAROUSEL_TECHNICAL_SPECS.md** - Спецификации карусели отзывов
- **CSS_OPTIMIZATION_IMPLEMENTATION_GUIDE.md** - Руководство по оптимизации CSS

### 💻 [`implementation/`](./implementation/)
Отчеты о реализации функциональности:
- **IMPLEMENTATION_SUMMARY.md** - Общий отчет о реализации
- **TRANSLATION_SYSTEM_IMPLEMENTATION.md** - Система многоязычности (RU/EN/ZH)
- **LANGUAGE_SWITCHER_MAIN_SITE_IMPLEMENTATION.md** - Переключатель языков
- **PRODUCTION_OPTIMIZATION_PLAN.md** - План оптимизации для продакшена

### 📊 [`reports/`](./reports/)
Отчеты о тестировании и оптимизации:
- **QA_REPORT.md** - Отчет о качестве и тестировании
- **OPTIMIZER_REPORT.md** - Отчет о работе оптимизатора
- **OPTIMIZATION_REPORT.md** - Отчет об оптимизации производительности
- **CAROUSEL_ARCHIVE_REPORT.md** - Архивный отчет по карусели

### 🔍 [`reflection/`](./reflection/)
Рефлексия и анализ проекта:
- **ARCHIVE_REFLECTION.md** - Итоговая рефлексия проекта

## 📝 Как использовать документацию

1. **Для разработчиков**: Начните с `architecture/TECHNICAL_REPORT.md`
2. **Для дизайнеров**: Изучите `implementation/` для понимания реализованных решений
3. **Для тестировщиков**: См. `reports/QA_REPORT.md`
4. **Для оптимизации**: См. `reports/OPTIMIZER_REPORT.md` и `architecture/CSS_OPTIMIZATION_IMPLEMENTATION_GUIDE.md`

## 🛠️ Технологический стек

- **HTML5** - семантическая разметка
- **CSS3** - ITCSS архитектура, CSS Custom Properties
- **JavaScript (ES6+)** - модульная структура
- **GSAP** - анимации
- **Webpack** - сборка проекта
- **Многоязычность** - RU, EN, ZH
