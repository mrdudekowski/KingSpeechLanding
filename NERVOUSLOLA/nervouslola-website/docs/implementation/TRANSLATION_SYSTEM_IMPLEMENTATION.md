## 🎯 РЕШЕНИЕ

### Создан новый модуль: `translation-applier.js`

**Функциональность:**
1. 📥 Загружает файлы переводов из `assets/data/translations/`
2. 🔄 Слушает событие `languageChanged` от language switcher
3. 🎨 Применяет переводы ко всем элементам с `data-key`
4. 💾 Сохраняет выбранный язык в localStorage
5. 🌐 Обновляет атрибут `lang` в HTML

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Класс TranslationApplier

```javascript
class TranslationApplier {
    constructor() {
        this.translations = {};        // Кэш переводов
        this.currentLanguage = 'ru';   // Текущий язык
        this.isLoading = false;        // Флаг загрузки
    }

    // Основные методы:
    async init()                       // Инициализация
    async loadTranslations(lang)       // Загрузка JSON
    getTranslation(key, lang)          // Получение перевода
    applyTranslations()                // Применение к DOM
    handleLanguageChange(lang)         // Обработка смены языка
}
```

### Процесс работы:

1. **Инициализация (при загрузке страницы):**
   ```
   DOMContentLoaded → init() → loadTranslations('ru') → applyTranslations()
   ```

2. **Смена языка (при клике на кнопку):**
   ```
   Клик на опцию → simple-language-switcher отправляет событие →
   translation-applier слушает событие → loadTranslations(lang) →
   applyTranslations() → Текст на странице обновляется
   ```

### Поддерживаемые атрибуты:

1. **`data-key`** - основной текст элемента
   ```html
   <h1 data-key="hero.title">Добро пожаловать</h1>
   ```

2. **`data-aria-label-key`** - aria-label для доступности
   ```html
   <button data-aria-label-key="accessibility.select_language">
   ```

3. **`data-alt-key`** - alt текст для изображений
   ```html
   <img data-alt-key="menu.icons.coffee" alt="Кофе">
   ```
