## 🔧 ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### **Порядок инициализации:**

```
1. DOM загружается
2. main.js (ES6 модуль) - инициализация основных компонентов
3. fallback.js - резервная система для file:// протокола
4. i18n-init.js - инициализация системы переводов
5. translation-manager.js - загрузка файлов переводов
6. language-switcher.js - создание UI компонента
7. dom-updater.js - обновление контента страницы
```

### **Обработка ошибок:**

```javascript
// Основная инициализация
try {
    await this.translationManager.initialize();
    await this.createLanguageSwitcher();
} catch (error) {
    // Fallback система активируется
    this.createFallbackLanguageSwitcher();
}
```
