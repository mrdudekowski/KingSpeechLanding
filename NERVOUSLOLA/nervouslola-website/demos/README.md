# 🎨 Демо и тесты проекта "Нервная Лола"

Коллекция демо-эффектов, вариантов компонентов и тестовых страниц.

## 📂 Структура

### ✨ [`effects/`](./effects/)
Демо креативных эффектов и анимаций:

1. **magnetic-cards.html** - Магнитные карточки с эффектом притяжения
2. **theater-curtains.html** - Театральные занавесы
3. **coffee-steam.html** - Анимация пара от кофе
4. **circus-showman.html** - Эффект циркового представления
5. **star-constellation.html** - Звездные созвездия
6. **living-painting.html** - Живая картина
7. **cinema-theater.html** - Кинотеатральный эффект
8. **inspiration-waves.html** - Волны вдохновения
9. **carnival-parade.html** - Карнавальный парад
10. **quantum-effects.html** - Квантовые эффекты

### 🍽️ [`menu-variants/`](./menu-variants/)
Варианты дизайна меню кофейни:

- **classic.html** - Классический вариант меню
- **modern.html** - Современный минималистичный стиль
- **minimal.html** - Минималистичный дизайн
- **elegant.html** - Элегантный утонченный вариант
- **typography.html** - Типографический акцент

### 🧪 [`tests/`](./tests/)
Тестовые страницы для проверки функциональности:

- **carousel.html** - Тестирование карусели отзывов
- **language-switcher.html** - Тестирование переключателя языков
- **aurora.html** - Тестирование эффекта aurora
- **markdown-preview.html** - Предпросмотр markdown
- **addons.html** - Тестирование дополнительных компонентов

## 🚀 Как использовать

1. Откройте `index.html` в корне папки demos для навигации по всем демо
2. Или откройте нужный файл напрямую в браузере
3. Для локального сервера используйте:
   ```bash
   npm run dev
   ```
   И перейдите по адресу `http://localhost:8080/demos/`

## 💡 Примечания

- Все демо используют те же assets (CSS, JS, изображения) что и основной сайт
- Пути к ресурсам настроены относительно корня проекта
- Для полной работы некоторых демо требуется запущенный dev-сервер
