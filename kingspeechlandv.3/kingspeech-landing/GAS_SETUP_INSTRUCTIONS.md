# 🔧 Google Apps Script Setup Instructions

## 📋 Пошаговая настройка GAS для KingSpeech Landing

### 1. Создание Google Apps Script проекта

1. **Откройте Google Apps Script**
   - Перейдите на https://script.google.com
   - Войдите в свой Google аккаунт

2. **Создайте новый проект**
   - Нажмите "Новый проект"
   - Переименуйте проект в "KingSpeech Landing Webhook"

3. **Удалите код по умолчанию**
   - Удалите весь код в `Code.gs`
   - Скопируйте код из `gas-webhook-enhanced.gs`

### 2. Настройка Telegram Bot

1. **Создайте Telegram Bot**
   - Найдите @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен

2. **Получите Chat ID**
   - Найдите @userinfobot в Telegram
   - Отправьте любое сообщение
   - Скопируйте ваш Chat ID

### 3. Настройка Google Sheets

1. **Создайте новую таблицу**
   - Откройте Google Sheets
   - Создайте новую таблицу
   - Переименуйте в "KingSpeech Leads"

2. **Настройте лист**
   - Переименуйте лист в "Leads"
   - Скопируйте ID таблицы из URL

### 4. Конфигурация GAS

1. **Обновите CONFIG в коде**
   ```javascript
   const CONFIG = {
     TELEGRAM_BOT_TOKEN: 'YOUR_BOT_TOKEN',        // Токен от BotFather
     MANAGER_CHAT_ID: 'YOUR_CHAT_ID',             // Chat ID от userinfobot
     SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID',       // ID таблицы из URL
     SHEET_NAME: 'Leads',                         // Название листа
     // ... остальные настройки
   };
   ```

2. **Замените значения**
   - `YOUR_BOT_TOKEN` → ваш токен бота
   - `YOUR_CHAT_ID` → ваш Chat ID
   - `YOUR_SPREADSHEET_ID` → ID вашей таблицы

### 5. Настройка прав доступа

1. **Разрешите доступ к Google Sheets**
   - В GAS редакторе нажмите "Разрешения"
   - Выберите "Review permissions"
   - Выберите ваш Google аккаунт
   - Нажмите "Advanced" → "Go to KingSpeech Landing Webhook (unsafe)"
   - Нажмите "Allow"

2. **Разрешите доступ к внешним URL**
   - GAS автоматически запросит разрешение при первом запросе к Telegram API

### 6. Развертывание Webhook

1. **Создайте развертывание**
   - В GAS редакторе нажмите "Развернуть" → "Новое развертывание"
   - Выберите тип "Веб-приложение"
   - Настройте параметры:
     - **Описание**: KingSpeech Landing Webhook
     - **Выполнять как**: Я
     - **У кого есть доступ**: Все

2. **Получите URL**
   - Нажмите "Развернуть"
   - Скопируйте URL веб-приложения
   - Это ваш GAS webhook URL

### 7. Тестирование

1. **Обновите конфигурацию в проекте**
   ```javascript
   // В gas-integration.js
   GAS_WEBHOOK_URL: 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec'
   ```

2. **Запустите тесты**
   ```bash
   python test_system_comprehensive.py
   ```

3. **Проверьте работу**
   - Отправьте тестовую заявку
   - Проверьте Google Sheets
   - Проверьте Telegram уведомления

## 🚨 Troubleshooting

### Частые проблемы

1. **"Script function not found"**
   - Убедитесь, что функции `doPost` и `doGet` существуют
   - Проверьте права доступа

2. **"Permission denied"**
   - Проверьте права доступа к Google Sheets
   - Убедитесь, что CONFIG заполнен правильно

3. **"Telegram API error"**
   - Проверьте токен бота
   - Проверьте Chat ID
   - Убедитесь, что бот не заблокирован

4. **"CORS error"**
   - Проверьте настройки CORS в GAS
   - Убедитесь, что домен разрешен

### Отладка

1. **Проверьте логи**
   - В GAS редакторе: Выполнения
   - Просмотрите логи выполнения

2. **Тестируйте функции**
   - Используйте функцию `testConfiguration()`
   - Проверьте каждую функцию отдельно

3. **Проверьте данные**
   - Убедитесь, что данные приходят правильно
   - Проверьте форматирование
