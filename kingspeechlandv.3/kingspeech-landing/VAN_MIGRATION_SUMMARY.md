## 🎯 Инструкции по развертыванию

### 1. Замена файлов в GitHub
```bash
# Клонируйте репозиторий
git clone https://github.com/mrdudekowski/KingSpeech.git
cd KingSpeech

# Создайте backup
git checkout -b backup-old-version
git add . && git commit -m "Backup old version"
git push origin backup-old-version

# Замените файлы
git checkout main
# ... замените все файлы из kingspeech-landing/
git add . && git commit -m "🚀 Complete migration"
git push origin main
```

### 2. Настройка GAS интеграции
1. Откройте [script.google.com](https://script.google.com)
2. Создайте проект "KingSpeech Landing Webhook"
3. Скопируйте код из `gas-webhook-enhanced.gs`
4. Замените `YOUR_BOT_TOKEN` и `YOUR_CHAT_ID`
5. Разверните как веб-приложение
6. Обновите URL в `js/modules/gas-integration.js`

### 3. Настройка Telegram Bot
1. Создайте бота через @BotFather
2. Получите Chat ID через @userinfobot
3. Настройте уведомления в группе
4. Протестируйте отправку сообщений
