### Этап 2: Развертывание в GitHub (45 минут)

#### 2.1 Клонирование и подготовка репозитория
```bash
# 1. Клонировать репозиторий
git clone https://github.com/mrdudekowski/KingSpeech.git
cd KingSpeech

# 2. Создать backup ветку
git checkout -b backup-old-version
git add .
git commit -m "Backup old version before migration"
git push origin backup-old-version

# 3. Вернуться на main
git checkout main
```

#### 2.2 Замена файлов
```bash
# 4. Удалить старые файлы
rm -rf css/ js/ assets/ fonts/ *.html *.js *.json *.ico *.md

# 5. Скопировать новые файлы
cp -r ../kingspeech-landing/css ./
cp -r ../kingspeech-landing/js ./
cp -r ../kingspeech-landing/assets ./
cp -r ../kingspeech-landing/fonts ./
cp ../kingspeech-landing/index.html ./
cp ../kingspeech-landing/favicon.ico ./
cp ../kingspeech-landing/aurora.js ./
cp ../kingspeech-landing/package.json ./
cp ../kingspeech-landing/.stylelintrc.json ./
cp ../kingspeech-landing/README.md ./
cp ../kingspeech-landing/QUICK_START.md ./
```

#### 2.3 Коммит и развертывание

git add .

### Этап 4: Настройка GAS интеграции (60 минут)

#### 4.1 Создание GAS проекта
1. Открыть [script.google.com](https://script.google.com)
2. Создать новый проект "KingSpeech Landing Webhook"
3. Скопировать код из `gas-webhook-enhanced.gs`
4. Настроить конфигурацию:
   ```javascript
   const CONFIG = {
     TELEGRAM_BOT_TOKEN: 'YOUR_BOT_TOKEN',
     MANAGER_CHAT_ID: 'YOUR_CHAT_ID',
     SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID',
     SHEET_NAME: 'Leads'
   };
   ```

#### 4.2 Создание Telegram бота
1. Найти @BotFather в Telegram
2. Отправить `/newbot`
3. Следовать инструкциям
4. Сохранить токен бота

#### 4.3 Получение Chat ID
1. Найти @userinfobot в Telegram
2. Отправить любое сообщение
3. Скопировать Chat ID

#### 4.4 Развертывание GAS
1. В GAS редакторе нажать "Развернуть" → "Новое развертывание"
2. Выбрать тип "Веб-приложение"
3. Установить доступ "Все пользователи"
4. Скопировать URL веб-приложения

#### 4.5 Обновление конфигурации
1. Открыть `js/modules/gas-integration.js`
2. Заменить URL:
   ```javascript
   GAS_WEBHOOK_URL: 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec'
   ```
